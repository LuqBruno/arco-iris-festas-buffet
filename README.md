# Arco-Íris Festas Buffet — prévia

Prévia comercial independente produzida por Bruno Luque, com fotografias e informações do perfil oficial [@arcoirisfestasbuffet](https://www.instagram.com/arcoirisfestasbuffet/), consultado em 24/11/2026. Não representa aprovação ou contratação pelo estabelecimento.

## Executar

Node.js 22+; `npm ci`, `npm run dev`. Checagem: `npm run check`. Produção: `npm run build`. Publicação por branch main, pasta `/docs`, gerada com `npm run build:pages`.

## Organização

- `index.html`: conteúdo semântico, navegação e formulário.
- `style.css`: tokens, fontes locais, composição responsiva e fallback.
- `main.js`: Motion, carrossel Embla, menu e mensagem do WhatsApp.
- `public/assets`: fotos WebP e logo oficiais; SVG original de autoria BL.
- `docs`: build publicado no GitHub Pages.

## Experiência

A mesma foto de uma festa se expande com a rolagem e apresenta a experiência do espaço. Rolagem nativa, reversível, sem capturar roda do mouse ou toque. O carrossel é manual, com arraste, toque, setas e teclas Home/End. Preferência de movimento reduzido e ausência de JavaScript preservam conteúdo, imagens e contato.

O formulário somente prepara uma mensagem para o WhatsApp oficial (48) 99627-8305. Não reserva data, não envia mensagens automaticamente e não armazena dados.
